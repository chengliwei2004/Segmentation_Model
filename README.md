# 茶壶分割模型设计

## 1. 项目背景
本项目致力于解决复杂场景下（如高曝光、玻璃反光、低对比度环境）紫砂壶（Zisha Teapot）的像素级目标分割问题。


现有的紫砂壶研究多集中于图像分类任务，而本项目旨在构建一套完整的端到端语义分割流水线，以实现对紫砂壶轮廓的精准提取，为后续的形制分析、智能鉴定提供底层视觉支持。

## 2. 模型与系统设计 (Model & System Design)
本项目并未盲目堆砌模型，而是针对紫砂壶数据集的特定痛点（高分辨率、玻璃罩反光干扰、目标与背景颜色相近）进行了定制化的系统架构设计。

### 2.1 核心网络架构选型 (Architecture Choices)
我们采用了基于 **DeepLabV3+** 的编码器-解码器（Encoder-Decoder）架构，并进行了以下适配性设计：
* **深度可分离卷积主干 (Xception Backbone)：** 鉴于紫砂壶表面存在复杂的反光与纹理（如泥料颗粒感），我们放弃了轻量级的 MobileNet，选用了特征表达能力更强的 Xception 作为 Encoder，在控制参数量的同时极大提升了对反光干扰的鲁棒性。
* **多尺度感受野融合 (ASPP 模块)：** 紫砂壶的器型变化丰富（如提梁、壶嘴尺度差异大）。模型利用 ASPP（空洞空间金字塔池化）模块，通过不同采样率的空洞卷积，并行抓取壶身的主体宏观特征与壶嘴/把手的微观边缘特征，有效解决了颜色融合处的边界模糊问题。

### 2.2 数据流水线与去噪设计 (Data Pipeline Engineering)
针对开源数据标注中常见的 JPG 有损压缩导致的“掩码边缘噪点”问题（该问题会导致传统 Dataloader 抛出交叉熵越界错误），本项目独立设计并编写了自动化的数据清洗与转换流水线 (`organize_dataset.py`)：
1. **灰度空间映射与阈值滤波：** 动态读取混合数据集，利用自定义阈值算法对掩码边界的压缩渐变噪点进行二值化切除。
2. **张量索引对齐：** 将清洗后的目标像素精确映射为类别 ID（Target ID = 1），并无损重构为单通道 PNG 格式。
3. **IO 解耦：** 自动分离训练原图与标签集，完美桥接 PyTorch 的 Dataset 接口，极大提升了数据加载的健壮性。
